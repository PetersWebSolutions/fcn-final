# FCN Medical & Vaccination Center

A pixel-faithful, production-ready marketing site for a travel-health clinic, built with **React 19**, **Vite**, and **Tailwind CSS v4**.

- Travel medicine, vaccination, Yellow Fever / BOQ assistance, PPD testing
- Interactive vaccine directory with search + filters
- Appointment request form with success state
- Testimonial carousel with autoplay (pause on hover)
- Scroll-spy navigation, scroll-reveal animations, animated count-up stats
- Fully responsive from mobile to desktop

## Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4 (single-file build via `vite-plugin-singlefile`)

## Scripts

```bash
npm install     # install deps
npm run dev     # start the dev server
npm run build   # build a production bundle into dist/
npm run preview # preview the production build
```

## Deploy

The built `dist/index.html` is fully self-contained (all CSS/JS inlined) and can be dropped onto any static host — GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.
